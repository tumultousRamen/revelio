# ADR 0005 — Name: Revelio

Date: 2026-05-12
Status: Accepted

## Context

Need a brandable, memorable name that suggests the product's core function: revealing the hidden truth of AI-tooling ROI, usage patterns, and engineering outcomes.

Candidates considered: Hindsight, Vantage, Mosaic, Prism, Lumos, Litmus, Augur, Revelio.

## Decision

**Revelio** — the Latin-rooted "reveal-the-hidden" metaphor maps directly to the product thesis. Distinctive, brandable, evocative.

## Consequences

- **Trademark check needed**: Revelio Labs (revelio.com) is a workforce / HR analytics company in an adjacent (but distinct) space. Likely coexists, but legal review before any public launch.
- **Domain priorities**: lock down `revelio.dev`, `revelio.io`, `getrevelio.com`. Do not chase `revelio.com`.
- HP-spell association is brand upside, not liability — but external copy should describe the name as "Latin-derived" rather than a Harry Potter reference, to avoid IP confusion.
- Tagline candidates to test: "Reveal what is hidden in your team's AI coding sessions." / "See how, not what." (the latter doubles as a privacy-posture tagline — see [ADR 0004](./0004-privacy-and-data-plane.md)).
